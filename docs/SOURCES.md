# Sources and research methodology

Use the strongest available source for each claim and link directly to the relevant page or document.

## Source priority
1. OEM support pages, user manuals, official technical specifications and antenna diagrams.
2. OEM service documentation and regulatory filings that clearly identify the exact model.
3. Credible teardowns or independent physical testing.
4. Reputable technical databases and specialist NFC references.
5. Community reports, used as leads that require corroboration.

## Record source scope
For every source, note:
- exact model name and model code covered
- region/market
- whether it confirms NFC capability, antenna location, or both
- publication/document date when available
- page number or figure number for manuals/PDFs

A source confirming that a phone has NFC does not automatically confirm where its antenna is. A diagram for one regional variant must not silently be applied to all variants.

## Research workflow
1. Identify all released retail models in the family.
2. Find exact model codes and markets.
3. Verify NFC capability per variant.
4. Search OEM manuals/support pages for antenna diagrams or location text.
5. Record the diagram and its source; distinguish official from independent evidence.
6. Mark unresolved details explicitly and revisit them when new evidence appears.
